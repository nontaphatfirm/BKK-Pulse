# Canonical Data Contract & Interface Specification (`DATA_CONTRACT.md`)

> **Purpose:** This document defines the strict schema, data types, primary keys, and temporal alignment rules for all shared datasets across modules `00` through `06`. Adhering to this contract guarantees zero-friction integration between Data Engineering, Data Science, and BI Dashboard components.

---

## 1. Global Engineering Standards & Critical Edge Cases

1. **Primary Camera Identifier (`cam_id`):**
   - Must always be stored as a 64-bit integer (**`int64`**) across all tables (e.g., `26`, `136`, `1804`). Never store `cam_id` as a zero-padded string or float.
2. **Temporal Key (`timestamp`) & Timezone Convention:**
   - All timestamps represent local Bangkok time (**Asia/Bangkok, UTC+7**) stored as **timezone-naive `datetime64`** (`datetime64[us]` or `datetime64[ns]` in Pandas 2.2+ / PyArrow) for seamless joins across Pandas, PyArrow, and DuckDB. Validate with `pd.api.types.is_datetime64_any_dtype` or normalize via `pd.to_datetime(df["timestamp"]).astype("datetime64[us]")`.
   - CCTV frames are captured at approximately **10-minute intervals between `06:00:00` and `21:00:00`** from `2026-08-25` through `2026-08-31`.
   - When joining 10-minute frame observations with hourly external datasets (`external_weather_poi.parquet`), floor the frame timestamp to the nearest hour via `df["timestamp"].dt.floor("h")`.
   - Run `python run_pipeline.py --check-contract` at any time to validate canonical Tables 1-4 against this specification.
3. **Handling `"None"` Literals in CSV vs. Parquet:**
   - In `cctv_info_cleaned`, standalone cameras without a directional pair use the string literal `"None"` in `pair_id`, `pair_type`, and `direction`.
   - **Always prefer reading `.parquet` files (`pd.read_parquet(...)`)**, which preserve exact types and string literals.
   - If reading `cctv_info_cleaned.csv` with Pandas, pass `keep_default_na=False` (or `.fillna("None")`) so Pandas does not coerce `"None"` into `NaN`.
4. **Camera `395` Resolution Exception:**
   - **99 cameras** capture frames at **`352 x 288` pixels** (`101,376` pixels total).
   - **Camera `395` (Sao Chingcha Intersection)** captures valid frames at **`348 x 261` pixels** (`90,828` pixels total), while its blank white error placeholders are `400 x 266`. Never hardcode `352 x 288`; always reference `img_width` and `img_height` from `cctv_info_cleaned.parquet` or actual frame dimensions.
5. **Known Temporal Discontinuities (Data Gaps):**
   - **Overnight Recording Window (`21:00-06:00` daily):** No images are recorded overnight in the raw dataset.
   - **Central Acquisition Outage (`2026-08-27 06:00-08:50`):** All 100 cameras experienced a simultaneous central ingestion outage on Wednesday morning, August 27, 2026 (recording resumed at `08:51`). Time-series lag operations in Task 05 must never shift across overnight boundaries or across this outage window.

## 4. Canonical Integration Snippet (For Tasks 04, 05, and 06)

```python
from pathlib import Path
import pandas as pd

PROJECT_ROOT = Path(__file__).resolve().parents[2]

# 1. Load canonical Parquet tables
meta_df = pd.read_parquet(PROJECT_ROOT / "Dataset_Clean_V1" / "cctv_info_cleaned.parquet")
manifest_df = pd.read_parquet(PROJECT_ROOT / "Dataset_Clean_V1" / "image_quality_manifest.parquet")

veh_path = PROJECT_ROOT / "data" / "vehicle_counts.parquet"
if not veh_path.exists():
    veh_path = PROJECT_ROOT / "data" / "vehicle_counts_sample.parquet"
veh_df = pd.read_parquet(veh_path)

ext_df = pd.read_parquet(PROJECT_ROOT / "data" / "external_weather_poi.parquet")

# 2. Merge frame-level vehicle detections, visual quality metrics, and camera metadata
df = (
    veh_df.merge(
        manifest_df[["cam_id", "timestamp", "brightness_mean", "contrast_std", "glare_ratio"]],
        on=["cam_id", "timestamp"],
        how="left",
    )
    .merge(
        meta_df[
            [
                "cam_id",
                "location_th",
                "location_en",
                "district",
                "corridor",
                "pair_id",
                "pair_type",
                "direction",
                "lat",
                "lon",
            ]
        ],
        on="cam_id",
        how="left",
    )
)

# 3. Align to hourly resolution and join external weather, POI, and Traffy Fondue features
df["hour_ts"] = df["timestamp"].dt.floor("h")
df = (
    df.merge(
        ext_df,
        left_on=["cam_id", "hour_ts"],
        right_on=["cam_id", "timestamp"],
        how="left",
        suffixes=("", "_ext"),
    )
    .drop(columns=["timestamp_ext"])
)
```
